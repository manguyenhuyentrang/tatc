Thanh thời hạn trong thẻ hồ sơ khiếu nại, tố cáo (v155).

- Hàng trên: nhãn hạn (còn/quá hạn, nền `*-tint` theo mức) + "Hạn dd/mm/yyyy"; dưới: thanh 8px nền `surface-sunken`, phần đã qua tô `brand-800` (trong hạn), `warning` (sắp hết), `danger` (quá hạn).
- Bên dùng cung cấp: `label`, `value` (số ngày đã qua), `max` (tổng số ngày), tùy chọn `level`, `due`.
