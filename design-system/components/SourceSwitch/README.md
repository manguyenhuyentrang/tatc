Hai thẻ chọn nguồn hồ sơ (màn Khiếu nại — Tố cáo: Hệ thống KNTC / Hệ thống QLA), đóng vai trò tab.

- Hàng trên: hình minh họa 28px bên trái (70% cỡ gốc), nhãn hệ thống bên phải cùng hàng (vàng `gold-soft` hoặc đỏ nhạt `brand-tint`, biểu tượng `swap`); tên 14/20 700; dòng phụ "n hồ sơ".
- Thẻ đang chọn: nền `warning-tint`, viền 1px `warning-border` – cùng kiểu banner nhắc cam kết (v177). Thẻ còn lại nền trắng + bóng thẻ.
- Bên dùng cung cấp: `items` (`key`, `title`, `system`, `tone`, `meta`, `illustration`), `value`, `onChange`.
